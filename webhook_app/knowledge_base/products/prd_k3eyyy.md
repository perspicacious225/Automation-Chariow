## 6. Protocole d'installation — résumé complet

### Phase A — Préparation (important)

Si une ancienne version d'Office est déjà installée sur le PC, elle doit être désinstallée proprement avant de commencer.

**Désinstallation standard (cas simple) :**
1. Aller dans Panneau de configuration → Programmes → Désinstaller un programme
2. Sélectionner Microsoft Office (version actuelle)
3. Cliquer sur Désinstaller
4. Redémarrer le PC

**Désinstallation complète avec nettoyage (cas d'erreur) :**
Si l'installation échoue après la désinstallation standard, des fichiers résiduels sont probablement présents. Utiliser l'outil officiel gratuit de Microsoft :

- Nom : Microsoft Support and Recovery Assistant (SaRA)
- Téléchargement : https://aka.ms/SaRA-OfficeUninstall
- Cet outil supprime automatiquement tous les fichiers résiduels d'Office
- Après utilisation : redémarrer le PC avant de lancer la nouvelle installation
- Une vidéo dédiée à ce cas est disponible dans le portail : [LIEN DRIVE VIDÉO 2 À RENSEIGNER]

### Phase B — Téléchargement d'Office 365

Le lien de téléchargement est fourni dans le document PDF de licence disponible sur portal.chariow.com.

- Durée estimée : 5 à 30 minutes selon la qualité de la connexion
- Laisser le PC branché et connecté pendant toute la durée du téléchargement
- Ne pas fermer la fenêtre de téléchargement
- Préférer le WiFi aux données mobiles pour plus de stabilité

### Phase C — Installation

1. Ouvrir le fichier téléchargé
2. Clic droit → Exécuter en tant qu'administrateur (Windows)
3. Suivre les instructions à l'écran
4. Durée estimée : 15 à 30 minutes
5. Ne pas interrompre l'installation — laisser le PC tranquille

### Phase D — Activation

1. Ouvrir Word ou Excel après l'installation
2. Suivre les instructions d'activation affichées
3. Saisir la clé d'activation fournie dans le document PDF (copier-coller sans espaces)
4. L'activation se fait automatiquement en ligne
5. Une fois activé, Office est disponible sur cet appareil à vie

## 7. Problèmes courants et solutions

### Problème 1 : "Je n'ai pas reçu l'email de confirmation"
**Solution :**
- Vérifier le dossier spam/courrier indésirable
- Le délai normal est de 5 à 10 minutes
- Vérifier que l'email entré lors du paiement est correct
- Si toujours rien après 15 minutes → contacter le support avec le numéro de transaction

### Problème 2 : "La clé d'activation ne fonctionne pas"
**Causes possibles et solutions :**
- Ancienne version d'Office encore présente → la désinstaller complètement avec l'outil SaRA
- Copier-coller la clé avec des espaces accidentels → copier à nouveau sans espaces avant/après
- Antivirus bloquant l'activation → désactiver l'antivirus temporairement pendant l'activation
- Si le problème persiste → Vidéo 2 disponible : [LIEN DRIVE VIDÉO 2 À RENSEIGNER]

### Problème 3 : "L'installation échoue ou affiche une erreur"
**Cause fréquente :** ancienne version d'Office mal désinstallée, fichiers résiduels présents.
**Solution :**
1. Utiliser l'outil officiel Microsoft SaRA : https://aka.ms/SaRA-OfficeUninstall
2. Laisser l'outil nettoyer tous les fichiers résiduels
3. Redémarrer le PC
4. Relancer l'installation
5. Vidéo 2 dédiée à ce problème : [LIEN DRIVE VIDÉO 2 À RENSEIGNER]

### Problème 4 : "Office s'affiche en anglais"
**Solution :**
1. Ouvrir Word ou Excel
2. Aller dans Fichier → Options → Langue
3. Ajouter "Français (France)" ou "Français (Côte d'Ivoire)" comme langue d'affichage
4. Définir comme langue par défaut
5. Fermer et rouvrir Office

### Problème 5 : "Le téléchargement est très lent ou s'interrompt"
**Solution :**
- Préférer une connexion WiFi stable aux données mobiles
- Laisser le PC branché et connecté toute la nuit si nécessaire
- Si la connexion coupe longtemps → le téléchargement peut s'interrompre → relancer depuis le portail
- Le fichier fait environ 2 à 3 Go — normal que ça prenne du temps avec une connexion lente

### Problème 6 : "Je ne retrouve pas ma licence dans le portail"
**Solution :**
- Vérifier l'email utilisé lors du paiement — certains clients ont plusieurs adresses
- Essayer avec l'adresse Gmail, Yahoo, ou professionnelle selon ce qui a été renseigné au paiement
- Contacter le support en indiquant le numéro de transaction

### Problème 7 : "Word refuse de s'ouvrir après installation"
**Solution :**
1. Redémarrer le PC
2. Si le problème persiste → vérifier que l'activation a bien été effectuée
3. Ouvrir Word → si une fenêtre d'activation apparaît → saisir la clé
4. Si toujours bloqué → contacter le support WhatsApp avec une capture d'écran du message d'erreur
